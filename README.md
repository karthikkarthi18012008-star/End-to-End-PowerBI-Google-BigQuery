# 🏠 Housing Market Analysis — Power BI & Google BigQuery

An end-to-end **Housing Market Analytics** project built using **Google BigQuery, SQL, Microsoft Power BI, Power Query, and DAX**.

The project focuses on analyzing housing sales performance, property prices, regional trends, sales types, market changes, and key housing indicators through interactive Power BI dashboards.

---

## 📌 Project Overview

This project demonstrates how cloud-based data can be transformed into meaningful business insights using **Google BigQuery and Power BI**.

The workflow starts with housing-market data uploaded to Google BigQuery. SQL is used to explore and prepare the data before connecting BigQuery with Power BI.

Inside Power BI, the data is further transformed using Power Query and analyzed using DAX measures. Multiple interactive dashboards were created to understand housing prices, sales performance, regional trends, and year-over-year changes.
